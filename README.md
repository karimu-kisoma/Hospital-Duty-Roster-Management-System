# Hospital-Duty-Roster-Management-System
A web based Hospital Duty Roster Management System developed using php, HTML, CSS, JavaScript and MariaDB
Technologies used php 8.2.12, HTML5, CSS3, JavaScript, MariaDB 10.4.32, Apache 2.4.58  and XAMPP 3.3.0 Bootstrap 5.3.2
Installation xampp, creat file on htdocs, open phpMyAdmin, create database, to start apache and mysql and open the project in the browser.
FEATURES ADMIN AND STAFF
ADMINFEATURES
Manages users, manage staff, Assign duty, view dutyroster, Aprove or Reject leave request, view staff comments and dashboard notification
USER FEATURES.
View duty roster, submit leave request, submit comment and view leave request status
